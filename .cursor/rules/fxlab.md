# fxlab

Read `README.md` (architecture) and `CLAUDE.md` (conventions) before changing anything. This file is the session-persistent version of those rules.

## What it is

A **library**, not a template kit. Modules are building blocks that combine. If a module is a finished artefact with fields to fill in (an event poster, a business card, a scoreboard), it does not belong. The test: could this be the base of a hundred different pieces of work, or is it one piece of work with the words swapped?

## Build and test

```sh
./build.sh                 # → dist/fxlab.html (and dist/index.html for hosts)
python3 tests/run_all.py   # before claiming anything works
```

- Never hand-edit `dist/fxlab.html` — it is generated by `build.sh` from `src/`.
- New source files go into the `cat` list in `build.sh`, in dependency order (helpers before the modules that use them).
- After **any** change: rebuild and run `python3 tests/run_all.py`. All checks must pass (`render_all`, `looks`, `seams`, `tiles`, `compositions`, `exports`, `search`, `lifecycle`).
- Composition-engine work (stacking, `api.input`, `nonLocal`, mattes) must keep `tests/compositions.py` green. Regenerate goldens only with `--write` after inspecting the new frames.
- After a new module, also run `python3 tests/sheet.py out.png <module-id>` and **look at the rendered PNG**. Most bugs here are visual, not thrown errors. A module that compiles is not a module that works.
- The suite drives the built file in headless Chromium via Playwright. If it is missing: `pip install playwright && playwright install chromium`.

## Writing a module

Follow the `FX.register({...})` shape in `src/registry.js`'s header comment and `CLAUDE.md`.

- Correct `id` prefix per category: `tr-` `mx-` `gen-` `trt-` `fx-` `ovl-` `kt-` `lg-`.
- One-sentence `desc` a designer would say out loud. Plain British English, no marketing, no exclamation marks.
- Defaults that look good immediately at 1080×1350 with the placeholder sources. Fit sizes to the frame rather than hard-coding pixels. `fx-reframe` is the exception: identity default, so adding a framing utility does not crop the work.
- Params become uniforms `p_<id>`; colours also get `p_<id>_a` for opacity.
- Helpers: `R` range, `I` whole number, `C` colour, `T` toggle, `S` select, `X` text, `F` font, `L` logo.
- Canvas 2D modules use `kind:'2d'` and `draw(ctx, api)`. `api` gives `w h W H t p loop dur fps params input sample`. `api.input` is the incoming processed frame (preview- or tile-sized canvas), or `null` on a base with no input. The engine also pre-paints it before `draw()`.
- Whole-frame / far-neighbour samplers set `nonLocal: true` on `FX.register` so tiled print renders in one pass.
- Optional `search: ['distort']` is invisible Library-search metadata, not a second taxonomy. Add it only when name/desc would miss a designer’s word.

## Shared helpers — do not copy-paste

Check whether a helper already exists before adding one.

- GLSL prelude: `src/glsl.js` (`luma`, `fbm`, `hash12`, `rot`, `centered`, `aspect`, `blendMode`, `bayer8`, `tileTex`, `sdRoundBox`, `sdTri`…).
- Type: `src/kt.js` (`KT.fit`, `KT.layout`, `KT.stagger`, `KT.ground`, `KT.wrap`, `KT.text`, `KT.mixHex`, `KT.beats`, `KT.motionSlant`).
- Colour / misc: `src/registry.js` (`Util.hexToRgb`, `Util.family`, `Util.hash`, `Util.clamp`, `Util.textBlock`).
- Logos: `Brand` and `Assets.image` / `Assets.tinted`.
- Outlines: `Glyphs.layout`.

## Motion and loops

- Loop-based motion: drive from `uLoop` (`api.loop` in 2D) in **whole cycles**. Random per-item speeds break the loop.
- Timeline motion: drive from `uProgress` (`api.p`), which already has project easing and hold applied.
- If something legitimately cannot loop cleanly (wall-clock flicker, a scrubber that resets each cycle), add it to `tests/seams.py`'s `EXPECTED` list with a one-line reason. Do not let it silently fail the check.

## Preview vs output

`uRes` is the **output** size. The preview (and test sheets) may render smaller. Hairlines and anything in output pixels must use `uPx` (output px per rendered px).

## Feedback and aux

- `feedback:true` → `uPrev` is this module's previous output. Check its alpha to detect an unwritten buffer and seed from it.
- `aux(ctx, params, w, h)` draws a **whole-frame** helper canvas uploaded as `uAux`, even when print is rendering one tile. Optional `auxSize` sets that canvas size.

## Mix & mask is a base combiner

`mx-*` modules are **base** modules. They composite sources A and B (fitted, or prepared by a source process list) into the starting frame. They are not stack compositors. The stack sees `uInput` (plus A/B still bound). `fx-matte` is the stack primitive: it mattes the current processed frame against bound A, bound B or a colour. It is not a second processed input from the stack.

Prepare A/B (`sources.A.process` / `sources.B.process`) may contain only `FX.laneEligible` modules — Treatments and `fx-reframe`. Not a second stack, not a precomp, not independently timed. Empty lists must be a no-op. A Look owns Prepare the same way it owns the stack (missing field → `[]`). Changing the photograph keeps the lane. `FX.laneEligible` is the only eligibility list.

## Canvas 2D incoming frame

The engine paints the incoming processed frame onto the destination 2D canvas, then passes that same frame as `api.input` (`HTMLCanvasElement`, or `null` for a base with no input). The canvas is the current 2D buffer — preview render size, or the current print tile — not output `W×H`. It is a separate snapshot from the destination, so modules can `drawImage` / crop / reposition it. `KT.ground` “Over frame” relies on the pre-paint, not a 0,0 blit (that would misplace the tile during print). `api.source(k)` / `api.sample` still read bound sources A/B (fitted, or prepared if a source process list ran).

## Print / tiles (`nonLocal`)

Modules that sample far outside their own pixel cannot be tiled. Declare that on the module:

```js
FX.register({ id:'fx-kaleido', nonLocal:true, desc:'…', /* … */ });
```

Print reads `FX.byId[id].nonLocal` and renders that stack in one pass. `tests/tiles.py` checks the flag on every migrated module and still tiles a local stack.
`tests/compositions.py` guards a small named matrix of multi-module stacks against golden PNGs.

## Brand roles

Colour, font and logo params resolve from role links before modules see them. Pin a role with `C('bg','Ground','#141516','ground')`, or opt out with `false` when the module needs a literal (paper, pen inks).

## House style

- Code: two-space indent, single quotes, no semicolon-free lines, small helpers over clever one-liners. Comments explain *why*, not what.
- Keep `src/registry.js`'s header comment and `CLAUDE.md`'s module counts accurate.
- When removing or renaming a module, old projects reference it by id: they open with that layer skipped. Do not silently alias ids.
- Do not claim a module works without rendering it and looking at it.
