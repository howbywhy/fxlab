# Digital texture and image-treatment techniques as a taxonomy of art-directable looks

Method note: about 15 searches/fetches. Cited findings are from pages fetched or search snippets; anything under "Inferences" is my own synthesis or general domain knowledge NOT verified against a source in this session. Several technique areas (Worley, curl, reaction-diffusion, Truchet, kaleidoscope, feedback, foil/iridescence, LUT, stippling, emboss) were not researched with sources; they appear only as flagged inference/gaps.

## Q1. Technique inventory: what each is, signature, parameters, algorithms, pitfalls; foundational vs composite

### Takeaway
Most looks reduce to a small set of primitives: (a) per-pixel tone/colour maps, (b) a threshold against a spatial pattern (ordered/blue-noise/dot-screen), (c) neighbourhood filters (blur, edge, Kuwahara), (d) coordinate warps, (e) procedural noise, (f) blend/compose. Error diffusion is the one common technique that is NOT a point/local operation and does not parallelise on a GPU.

### Cited Findings
- Ordered dithering = a preset threshold map tiled over the image; Bayer is the most common and gives noticeable crosshatch patterns; Bayer maps are generated with simple bitwise operations and look structured/artificial — [Wikipedia: Ordered dithering](https://en.wikipedia.org/wiki/Ordered_dithering); [Dizzy Dithering](https://liamappelbe.medium.com/dizzy-dithering-2ae76dbceba1)
- Blue-noise dither removes low-frequency ("pink") content, retaining sharp detail without the visible artefacts of ordered dither — [Wikipedia: Ordered dithering](https://en.wikipedia.org/wiki/Ordered_dithering)
- Blue-noise textures: uniform value distribution (usable directly as thresholds), weak low frequencies, isotropy. Generated by void-and-cluster (place each next value at the "darkest" point of a Gaussian-blurred binary mask); Gaussian sigma of 1.9 px recommended; cost O(n² log n), seconds for 64², days for 1024²; small tiles (64² or less) tile acceptably because wrapping is handled at borders during construction — [Moments in Graphics blue noise](https://momentsingraphics.de/BlueNoise.html)
- Error diffusion kernels: Floyd–Steinberg weights 7,3,5,1 /16; Jarvis–Judice–Ninke 5x3 kernel /48; Atkinson propagates only 3/4 of the error (hence higher contrast, clipped extremes); serpentine scanning reduces directional artefacts; error diffusion is an "area operation" needing buffering, unlike point-wise ordered dither — [Wikipedia: Error diffusion](https://en.wikipedia.org/wiki/Error_diffusion)
- Practical consequence: a WebGL riso tool notes Floyd–Steinberg/Atkinson cannot run in a fragment shader, so it runs them on the CPU and uploads the result as a texture — [chuwd19/overprint](https://github.com/chuwd19/overprint)
- Riso/overprint tool distinguishes amplitude screens (dot, diamond, square, line: fixed grid, mark size varies with tone) from frequency screens (grain, Bayer, Atkinson, FS: same-size marks, density varies) — [chuwd19/overprint](https://github.com/chuwd19/overprint)
- Halftone dot shader: distance to cell centre with smoothstep; cell grid by fract/floor; dot radius should be `maxRadius * sqrt(coverage)` (area proportional to tone); anti-alias width via `fwidth` so it is pixel-ratio independent; sample the source at the cell centre (floor-quantised UV) so a whole dot takes one colour; sampling 3x3 neighbour cells lets dots grow past cell walls without clipping; `smoothmin` gives "gooey" merging dots — [Maxime Heckel, Shades of Halftone](https://blog.maximeheckel.com/posts/shades-of-halftone/)
- CMYK halftone: RGB→CMYK via min of inverted channels / (1-k); four rotated grids (C 15°, M 75°, Y 0°, K 45°); subtractive composite `White*(1-C)*(1-M)*(1-Y)` versus additive RGB — [Maxime Heckel](https://blog.maximeheckel.com/posts/shades-of-halftone/)
- Why those angles: yellow (lightest) at 0°, black at 45° (least visible diagonal); 30° offsets between screens give stable "rosette" moiré; the 15° cyan/yellow interaction is the most visible moiré (about 3.83x the screen pitch) and shows in reds/greens — [PrintPlanet/print guides via search](https://printplanet.com/threads/screen-angles-why-are-they-15-45-75-and-90.10650/); [Wasatch on moiré](https://www.wasatch.com/htmlHelp/en/color_separations/moire.html)
- Riso simulation chain: separate image into 1–3 spot inks (tonal bands by luminance in simple tools), screen each ink separately, multiply-overprint, offset each ink after the first for misregistration (real range quoted as 1–4 mm), add ink grain/paper fibre texture — [Effect.app risograph](https://effect.app/effects/risograph); [Studio 2AM](https://studio2am.co/blogs/news/the-risograph-effect-ink-misregistration-for-zines-gig-posters-and-editorial-work); [chuwd19/overprint](https://github.com/chuwd19/overprint)
- Overprint tool extras: highlight knockout (no ink below a coverage threshold so paper white survives), ink fade toward trailing edge, roller streaks, hand-cut rough edges, coloured paper stocks (dark stock caps highlights at paper reflectance); Beer–Lambert separation gave washed-out mids, so it uses a coverage-linear model with Gauss–Newton inversion; frequencies in lines-per-inch so 3x exports keep identical dot sizes — [chuwd19/overprint](https://github.com/chuwd19/overprint)
- Paper Shaders dithering: shape sources (simplex, warp, dots, wave, ripple, swirl, sphere), types random/2x2/4x4/8x8, `size` 1–20, two colours (back/front), plus common `scale` 0.01–4, rotation, offsets, `minPixelRatio`, `maxPixelCount` — [Paper Shaders: Dithering](https://shaders.paper.design/dithering). Paper's library also lists halftone dots, heatmap, paper texture (abstract/cardboard/details variants) — [Paper Shaders](https://shaders.paper.design/)
- Kuwahara: classic filter picks the lowest-variance sector mean; the anisotropic version squeezes/rotates the kernel using the smoothed structure tensor, giving sharper edges and oil-paint-like flow while staying temporally coherent — [Kyprianidis GPU Pro page](https://www.kyprianidis.com/p/gpupro/); paper: [Kang et al. TPCG 2010](https://www.umsl.edu/~kangh/Papers/kang-tpcg2010.pdf); implementations at [Lygia](https://lygia.xyz/filter/kuwahara) and [Heckel painterly](https://blog.maximeheckel.com/posts/on-crafting-painterly-shaders/)
- Film grain: real grain is heavier in shadows than highlights, applied in scene-linear space rather than after the display transform, and reseeded each frame — [StraySpark Blender film look](https://www.strayspark.studio/blog/blender-film-look-halation-grain-gate-weave); colourist view: grain is the developed structure of the image, scales with density, per-channel, finer in shadows and visible in midtones — [Pixel Tools film emulation](https://pixeltoolspost.com/blogs/resolve/film-emulation-explained)
- Halation vs bloom: halation is a warm red-orange halo from light bouncing off the film base and re-exposing the emulsion (red-weighted blur of highlights); bloom is a neutral symmetric lens/eye glow. One implementation notes deriving blur size/sigma from a radius alone makes halation resolution-independent — [StraySpark](https://www.strayspark.studio/blog/blender-film-look-halation-grain-gate-weave); [CostardRouge/atelier PR 144](https://github.com/CostardRouge/atelier/pull/144); [LearnOpenGL physically based bloom](https://learnopengl.com/Guest-Articles/2022/Phys.-Based-Bloom)
- Film emulation stage order: negative (toe/shoulder curve) → print stock S-curve (e.g. Kodak 2383) → halation → grain → process variants (bleach bypass = higher contrast, desaturated; push/pull; cross-process) — [Pixel Tools](https://pixeltoolspost.com/blogs/resolve/film-emulation-explained)
- VHS: chroma recorded at a fraction of luma bandwidth so colour lags/bleeds; head-switching band at the bottom; tracking bands; dropouts; vertical roll; edge wave. CRT: scanlines, phosphor glow, curvature, shadow-mask/aperture-grille RGB triads — [Modulate VHS](https://modulate.to/effects/vhs/); [Vayce CRT](https://vayce.app/tools/crt-screen-effect/); [NTSCRT](https://github.com/finnmckenty/NTSCRT)
- Pixel sort: Asendorf's ASDFPixelSort (2010, Processing); walk each line, find intervals defined by a brightness threshold mask, sort each interval by brightness/hue/saturation; original sorted vertically then horizontally — [Satyarth](https://satyarth.me/articles/pixel-sorting/); [Modulate pixel sort](https://modulate.to/effects/pixel-sort/); [Kim Asendorf](https://kimasendorf.com/mountain-tour/pixel-sorting-meeting-chaos-half-way/)
- Unicorn Studio ships 70+ WebGL effects (noise overlays, edge glow, fluid, volumetric light, glyph dither, halftone, Sobel-based Outline with thickness/threshold/softness/intensity, Mondrian pixelation); an effect can act on everything beneath or as a child of one layer — [Unicorn Studio via search](https://www.unicorn.studio/docs/getting-started/); [Changelog](https://www.unicorn.studio/docs/changelog/)

### Inferences
Foundational primitives (my classification, not sourced):
1. Tone/colour point ops: levels, curves, threshold, posterise, gradient map (duotone/tritone = gradient map on luma), LUT, channel mixer, blend modes.
2. Pattern-threshold quantisers: one engine `out = step(threshold(x,y), tone)` where the threshold field is Bayer, blue noise, white noise, dot/line/ring cell distance, or any noise. So halftone, ordered dither, stochastic screen, "line halftone", ring/concentric screens, stippling (approximate) and even ASCII (cell → glyph by tone) are one family with different threshold fields. Worth building as one module with a pattern selector.
3. Neighbourhood filters: Gaussian/box/directional blur, unsharp, Sobel/DoG edge, Kuwahara, median, emboss (directional derivative → letterpress/deboss), mosaic/pixelate (quantised UV; a cheap special case).
4. Coordinate warps: displacement by noise/texture, liquid, swirl, kaleidoscope (fold angle mod), mirror, lens distortion, barrel/CRT curvature, scanline jitter/wave. Chromatic aberration = radially scaled per-channel UV offset. Glitch slices = per-band UV offset.
5. Generators: fbm, Worley, curl-noise flow, Truchet, reaction-diffusion (stateful, multi-pass), flow fields.
6. Stateful/multipass: feedback/echo trails, fluid, reaction-diffusion, error diffusion, pixel sort (needs per-line sort; feasible via bitonic/odd-even passes or CPU).
Composites (chains of primitives): riso = separation + per-ink screen + multiply + offset + paper grain; photocopy = contrast + threshold/blur + noise + edge darkening + slight skew; VHS = luma/chroma split blur + noise + scanline + jitter + tracking bands; halation film = curve + highlight extract + red blur + add + grain; Y2K chrome = gradient map on emboss/env-map-like ramp + bloom; foil/iridescence = view/normal-driven hue ramp (gradient map on noise-or-gradient-derived angle); glitch/datamosh = block displacement + channel shifts + quantise (true datamosh is a video-codec effect; a browser approximation is block motion-vector smearing).
Common pitfalls to pre-empt (partly sourced above, rest inferred): error diffusion is not shader-friendly so offer Bayer/blue-noise/Atkinson-look via CPU or approximation; dot radius must use sqrt(coverage) for tonal accuracy; halftone must sample at cell centre and antialias with fwidth-equivalent; Bayer levels must be scaled to threshold in (0,1) not integers; pixel sort on GPU needs a defined max interval length; Kuwahara cost scales with radius² so cap and offer scaled-down passes.

## Q2. Categorisation / mental model across tools

### Takeaway
Tools converge on a mix of function-based categories (colour, blur/sharpen, distort, stylise, noise/texture, generate, time) with look-based bundles layered on top (film, print, retro). The sourced evidence is thin; only Unicorn Studio and Paper Shaders were examined directly.

### Cited Findings
- Unicorn Studio: layer/effect model where an effect can affect everything beneath it or be a child of one layer; library of 70+ effects spanning utilities (noise overlay, edge glow) to centrepieces (fluid, volumetric light) — [Unicorn Studio docs](https://www.unicorn.studio/docs/getting-started/); [Abduzeedo](https://abduzeedo.com/webgl-design-tool-unicorn-studio-shaders)
- Paper Shaders splits into generators (mesh gradient, paper texture, etc.) and image filters (halftone dots, dithering, heatmap, sepia) with shared common props (scale, rotation, offset, fit, pixel-ratio caps) — [Paper Shaders](https://shaders.paper.design/); [Halftone dots](https://shaders.paper.design/halftone-dots)
- Lygia organises GLSL by function folders (e.g. `filter/kuwahara`) — [Lygia](https://lygia.xyz/filter/kuwahara)
- Colourist framing of film emulation as a pipeline (negative → print → halation → grain → process) — [Pixel Tools](https://pixeltoolspost.com/blogs/resolve/film-emulation-explained)
- Riso and print tools separate a pre-press stage (colour grades steering separation) from a post-press stage (colouring finished output) — [chuwd19/overprint](https://github.com/chuwd19/overprint)

### Inferences
Suggested two-axis model (mine): by mechanism (Tone & colour map; Screening/quantise; Neighbourhood/stylise; Distortion/warp; Generators/noise; Optics & light (blur, bloom, halation, CA, lens); Medium/artefact simulation (grain, riso, VHS, CRT, photocopy, scan); Glitch/data-corruption; Feedback/time; Composite/blend) and by pipeline position (Prepare tone → Screen/stylise → Distort → Optics → Medium artefacts → Grade/finish). Order matters: screening before optics (halation on dots looks like ink glow), grain/paper last, dither last of all in output space. Looks/recipes (Q5) sit above modules as presets, matching how film tools bundle stocks. My recollection is that Photoshop's gallery groups by Artistic/Blur/Brush/Distort/Noise/Pixelate/Render/Sketch/Stylize/Texture, and that TouchDesigner TOPs are grouped by Filter/Generators/Composite/GLSL; After Effects by Blur/Distort/Noise&Grain/Stylize/Simulation; Blender compositor by Color/Filter/Distort/Matte/Vector — none verified.

### Gaps
- Did not fetch docs for Photoshop, Affinity, Lightroom/VSCO/Dehancer/FilmConvert, TouchDesigner, After Effects, Magic Bullet, Cavalry, Blender; taxonomy claims for them are unverified.

## Q3. Parameters, ranges/defaults, resolution-independence pitfalls

### Takeaway
Key rule from the sourced tools: define spatial parameters in physical/relative units (cell size in lines-per-inch or fraction of frame, grain size in output pixels), antialias with derivative-based widths, and cap pixel ratio for performance.

### Cited Findings
- Overprint: sizes in real units (lines-per-inch at 150 ppi basis) so 3x exports keep identical dither/dot size — [chuwd19/overprint](https://github.com/chuwd19/overprint)
- Heckel: use `fwidth` for antialiasing edge width so appearance is independent of device pixel ratio — [Heckel](https://blog.maximeheckel.com/posts/shades-of-halftone/)
- Paper Shaders exposes `minPixelRatio`, `maxPixelCount`, `scale` 0.01–4, dither `size` 1–20 — [Paper dithering](https://shaders.paper.design/dithering)
- Halation resolution independence: derive blur buffer size and sigma from a radius parameter alone — [CostardRouge PR 144](https://github.com/CostardRouge/atelier/pull/144)
- Riso misregistration real-world range 1–4 mm — [Studio 2AM](https://studio2am.co/blogs/news/the-risograph-effect-ink-misregistration-for-zines-gig-posters-and-editorial-work)
- Blue-noise tiles of ≤64² tile acceptably but bigger is better for less repetition; tiling handled by wrapped construction — [Moments in Graphics](https://momentsingraphics.de/BlueNoise.html)
- Grain reseeds per frame in film look; for stills, seed is a user-visible parameter (inference from [StraySpark](https://www.strayspark.studio/blog/blender-film-look-halation-grain-gate-weave))

### Inferences
Parameter shortlist (my synthesis): Screening: cell size (as % of short edge or px at 1080 basis), angle, tone/contrast before screen, threshold bias, softness, ink/paper colours, shape. Dither: pattern, levels (colours), pixel size (integer, in output px), gamma-aware toggle. Grain: amount, size (output px), roughness, shadow-weighting, colour vs mono, seed. Halation/bloom: threshold, radius (% of frame), tint, strength. CA: strength (px at 1080), radial vs linear. Riso: ink count/colours, offset per ink (px), density, paper tooth, knockout threshold. Good immediate defaults: subtle-but-visible (grain 0.2–0.35, halation strength ~0.3, CA 1–3 px at 1080, misregistration 2–6 px at 1080, halftone cell ≈1.2–2% of frame height, dither pixel size 2–4 px) — these are my judgement, not sourced.
Pitfalls (inferred): preview vs export scale, so express radii in fractions of frame and sizes-in-pixels via an explicit "output px" basis; hairlines below 1 device px vanish or shimmer, clamp to ≥1 px or fade; neighbourhood effects (blur, Kuwahara, halation, sort, pixel-quantising) break at tile seams unless tiles overlap by the kernel radius or the module is marked non-local; noise/pattern coordinates must use global (frame) coordinates not tile-local; hash-based noise must not depend on tile origin; dither/threshold patterns anchored to global pixel coordinates; per-cell dot sampling must snap to global grid.

### Gaps
- No sourced "good default" numeric ranges for grain, halation, CA; none found in sources beyond those above.
- No source found on tiled-render seam handling specifically.

## Q4. Colour science essentials

### Takeaway
Blend/blur/grain in linear light for physical correctness, but 8-bit linear storage bands in shadows, so use float/half-float buffers and finish with dither at output.

### Cited Findings
- 8-bit channels are normally sRGB-encoded to allocate more codes to darks; storing linear values in 8 bits causes precision loss and shadow banding; linear blending needs more than 8 bits — [NVIDIA GPU Gems 3 ch.24](https://developer.nvidia.com/gpugems/gpugems3/part-iv-image-effects/chapter-24-importance-being-linear); [Nine Degrees Below](https://ninedegreesbelow.com/photography/linear-gamma-blur-normal-blend.html)
- Dithering replaces banding with less objectionable high-frequency noise; when dithering, account for gamma since 127.5/255 is ~22% linear light, not 50% — [Nayuki gamma-aware dithering](https://www.nayuki.io/page/gamma-aware-image-dithering); [Dithering in Gamma vs Linear Space](https://threadlocalmutex.com/?p=93); [Playdead banding](https://loopit.dk/banding_in_games.pdf)
- Grain should be applied in scene-linear space, not after the view transform — [StraySpark](https://www.strayspark.studio/blog/blender-film-look-halation-grain-gate-weave)
- Subtractive multiply model for CMYK/riso overprint — [Heckel](https://blog.maximeheckel.com/posts/shades-of-halftone/); [Effect.app](https://effect.app/effects/risograph)

### Inferences
Blend modes: multiply for inks/overprint, screen for light (halation, bloom), overlay/soft-light for grain; note that multiply in gamma space looks darker/harsher than linear multiply and many designer tools expect gamma-space behaviour, so offer a mode or match Photoshop by default (unverified how each tool behaves). Display P3: canvas `colorSpace:'display-p3'` widens gamut but spot-ink colours (riso pinks, fluorescents) are often outside sRGB, so P3 helps; caveat that exports (PNG/MP4) must tag/convert the profile. Banding fix: add ~1 LSB triangular (TPDF) noise or blue-noise before 8-bit quantise, in the final pass only. Gradient maps: interpolate stops in a perceptual or linear space, not naive sRGB, to avoid muddy mids (my opinion).

### Gaps
- Display P3 in WebGL2/Canvas specifics not researched.
- No source on Photoshop blend-mode maths or gamma-space defaults.

## Q5. Recipes for contemporary aesthetics

### Takeaway
Recipes below are mostly my own synthesis, constrained by sourced chains for riso, film/halation and VHS; parameter regions are judgement, not sourced.

### Cited Findings
- Riso: separate to 1–3 inks → per-ink halftone/grain screen → multiply overprint → misregistration → paper grain, optional highlight knockout — [chuwd19/overprint](https://github.com/chuwd19/overprint); [Effect.app](https://effect.app/effects/risograph)
- Film/halation: tone curve (toe/shoulder) → print S-curve → red-weighted halation on highlights → grain (shadow-weighted) → optional bleach bypass — [Pixel Tools](https://pixeltoolspost.com/blogs/resolve/film-emulation-explained); [StraySpark](https://www.strayspark.studio/blog/blender-film-look-halation-grain-gate-weave)
- VHS: chroma bleed, tracking wobble, head-switch band, tape grain, then CRT scanlines/curvature/phosphor on top — [Modulate VHS](https://modulate.to/effects/vhs/); [Vayce](https://vayce.app/tools/crt-screen-effect/)
- Glitch: pixel sort with threshold interval on highlights/shadows, often sorted in both axes; paired with bloom and chromatic aberration in Unicorn Studio-style stacks — [Satyarth](https://satyarth.me/articles/pixel-sorting/); [Unicorn Studio via search](https://www.unicorn.studio/docs/changelog/)

### Inferences
Ordered chains (typical regions, mine):
- Riso poster: contrast/levels → 2–3 ink separation → per-ink halftone or grain (angles 15/45/75 or 7.5° steps, cell ~1–2% frame) → multiply → offset 2–6 px @1080 → paper tooth + ink speckle → slight knockout.
- Dithered low-fi: downscale (pixel size 2–4) → levels/gamma → Bayer 4x4/8x8 or Atkinson → 1–4 colour palette map → nearest-neighbour upscale. No blur after.
- VHS nostalgia: soften luma slightly → blur chroma horizontally + offset → tracking band displacement + noise → scanlines → mild bloom → vignette/curvature.
- Halation film: exposure/contrast curve → warm-grade → threshold highlights → red-biased blur (radius 1–3% frame) → screen add → luminance-weighted grain (size 1–1.5 px) → gate weave/vignette.
- Photocopy/xerox zine: greyscale → high contrast/threshold → coarse grain or halftone → edge darkening/toner streaks → misregistered second pass → slight rotation, paper texture. (unsourced)
- Y2K chrome: emboss/height from shape or noise → gradient map with high-contrast sky/horizon ramp → specular/bloom → chromatic edge → optional grain. (unsourced)
- Glitch-punk: slice displacement + RGB split → pixel sort in highlights → scanline/blockiness → posterise/dither → hard contrast. (partly sourced)
- Painterly/analogue-digital: anisotropic Kuwahara → paper texture multiply → light grain → subtle halftone edge.
- Iridescent foil: noise/normal-driven angle → cyclic hue ramp gradient map → multiply/overlay onto base → specular sweep.
